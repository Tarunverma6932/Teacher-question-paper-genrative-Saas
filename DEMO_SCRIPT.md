# EduAssess Pro - 8 Minute Client Demo Script

## 0-1 min: Introduce problem
"Teachers spend hours drafting assessments manually. EduAssess Pro cuts this to minutes while preserving your question pattern."

## 1-2 min: Show sign-up and roles
- Open app
- Sign up as teacher
- Mention student role is separate and secure

## 2-4 min: Teacher workflow
- Upload PDF chapter
- Set pattern counts (`MCQ`, `Very Short`, `Short`, `Long`)
- Add pattern notes
- Click `Generate Paper`
- Show generated sections
- `Print` and `Export as Text`

## 4-5 min: Publish and management
- Click `Publish for Students`
- Show teacher analytics updating
- Show published history list and delete capability

## 5-6 min: Student workflow
- Login as student
- Open Student Assessment Feed
- Open published paper
- Point out answer key is hidden for students

## 6-7 min: Data and security
- Real auth (hashed passwords + token sessions)
- Shared DB-backed data (not local browser-only)
- Role-based API access

## 7-8 min: Deployment and scale
- Deployed on Render with health checks
- CI pipeline for reliability
- Phase-2 roadmap: Google OAuth + advanced AI + multi-school tenancy
